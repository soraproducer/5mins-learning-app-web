# Technical Stack

This project is a website app that helps users quickly learn the basics of any topic in around 5 minutes.
Examples questions: "The difference between PPO and GRPO," "The impact of the appreciation of the US dollar," or "The history of Nike vs Adidas."

# Core Components
1. Database (PostgreSQL):
    - Stores past conversations.
    - Supports loading, updating, and deleting saved sessions.
2. Backend (Python + FastAPI):
    - Handles communication between frontend, external LLM APIs, local LLM, and the database.
    - Supports SSE streaming to deliver Ollama output in real-time to the frontend.
3. Local LLM (Ollama with gemma3:12b):
    - Summarizes and compares answers from different LLMs.
    - Highlights consistent information and points out differences between sources.
4. 3rd-Party LLMs:
    - Multiple APIs are called with the same user question to gather diverse responses.
    - Use ChatGPT and Claude APIs
5. Frontend (React):
    - A chat-style web application similar to Claude or ChatGPT.
    - Users can enter topics via a text input box, view summarized knowledge, ask follow-up questions, and manage conversation history (save/delete).
    - The top right corner features two icons: Home and History.
    - Home: Users can input a question in the text box; upon submission, they are redirected to the conversation page with that question.
    - History: Users can revisit previous conversations to continue the dialogue or delete them directly from the history page.

# Data Flow Overview
Frontend (user ask question) → Backend → 3rd-party LLMs (gather data) → Backend → Local LLM (summarize data) → Backend → Frontend (present data) + Database (save data)

# Glossary
1. Message: A single message which stores the content given by the user, system, or assistant (LLM).
2. Conversation: A sequence of messages that together form a complete conversation.

# UI Components
0. Global Layout:
    - All Pages have two tabs on the top right: Home and History.
    - The UI follows a minimalist design using only black, grey, and white
1. Home Page:
    - A central text input box allows users to submit questions
    - Two adjacent dropdowns enable selection of expert LLMs (multi-select) and summarization model (local Ollama, single-select)
    - Submitting a question redirects users to the conversation page
2. History Page:
    - Displays a scrollable list of past conversations in chronological order
    - Each conversation item includes a brief summary
    - When the user hovers over a conversation item, a 3-dot icon appears on its right. Clicking the icon opens a dropdown menu with a "Delete" option to delete the conversation
3. Conversation Page:
    - A chat-style interface similar to ChatGPT or Claude
    - Messages are categorized as user, system, or assistant
    - Each assistant message includes a Retry button at the bottom left. Clicking Retry reveals dropdowns to reselect expert and summarization models for regeneration
    - At the bottom of the page is a text input box with the same model selection dropdowns as on the Home Page
